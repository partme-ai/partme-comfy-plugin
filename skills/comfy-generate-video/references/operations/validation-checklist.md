# comfy-generate-video 交付验证清单

## 输入

- [ ] 目标与非目标明确。
- [ ] 环境、版本、区域与身份来源明确。
- [ ] 高风险动作具有动作级授权。

## 执行

- [ ] 所有外部调用使用可信端点与 TLS 校验。
- [ ] 日志不含完整凭据或个人数据。
- [ ] 重试次数、超时和终态处理可预测。

## 输出

- [ ] `video-generation-result` 格式完整且可复查。
- [ ] `视频可播放且时长、帧率、分辨率和任务标识完整` 有真实证据。
- [ ] 失败、降级、回滚与剩余风险已说明。
- [ ] 事实、推断、示例和未验证项清晰区分。
