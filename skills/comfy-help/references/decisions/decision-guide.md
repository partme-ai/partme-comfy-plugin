# comfy-help 决策指南

## 目标

本技能用于诊断 Comfy 技能、模型、节点和连接问题并给出路由建议，主要交付物是 `comfy-help-report`。

## 决策树

1. 若授权范围不清晰：只输出只读检查方案和待确认项。
2. 若输入不完整但可安全假设：明确假设，先产出可审查草案。
3. 若存在生产写操作：先验证备份和回滚，再请求动作级确认。
4. 若需要绕过安全控制：停止，给出合规替代路径。
5. 若证据满足 `问题类别、证据、建议技能与下一步验证明确`：交付结果并记录验证方式。

## 近似场景边界

- `通用 Python 包或 GPU 驱动故障排查` 不属于本技能的直接职责，应转交更合适的专项技能或人工流程。
- 仅做知识问答时，不应触发任何外部写操作。
- 无法取得真实环境证据时，只能交付方案或推断，不能声称运行验证通过。
