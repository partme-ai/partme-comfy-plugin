# Privacy

PartMe Comfy is a local plugin foundation for Comfy Cloud workflows. It does not include telemetry, advertising, or a hosted data service.

The plugin may send user-approved prompts and workflow inputs to the Comfy Cloud service to perform generation, and downloads generated artifacts to user-selected paths. Credentials are stored only in the user's local configuration and are never embedded in this repository.

Users should review Comfy Cloud's own privacy terms before enabling the integration, and are responsible for the content they submit to third-party generation services.
